**Keputusan desain (mendorong perilaku, bukan hanya memindahkan kode):**
1. Tanda tangan dihitung atas **manifest hasil baca ulang dari jsonb**, bukan objek kiriman klien — yang ditandatangani harus byte-identik dengan yang disajikan katalog ke perangkat.
2. ZIP diperiksa lewat **Central Directory** tanpa dekompresi; material v1 STORE, jadi `uncompressedSize` setara `files[].bytes` dan berkas tak terdaftar (vektor XSS seperti `assets/curl.html`) tertolak meski manifestnya sah.
3. **ETag sebelum URL pre-signed** — kalau tidak, tiap halaman beda byte dan 304 tidak pernah terjadi. `generatedAt` diambil dari query terpisah agar stabil selama isi tidak berubah.
4. Cover gagal = `coverUrl` hilang (kosmetik, §6); URL bundel gagal = 502 (tanpa itu kartu tak bisa dipasang). Baris tanpa `signature`/`key_id` tidak pernah disajikan.
5. Unpublish menandai `unpublished_at`, **tidak menghapus** baris — riwayat `bundle_sha256` per versi diperlukan supaya §11.6 tetap bisa menolak "versi sama, isi berbeda".
6. Skrip penerbit tidak menerima kunci konten dalam bentuk apa pun; `ADMIN_API_TOKEN` hanya dibaca dari environment.

**Verifikasi aktual:** `npx vitest run workers/api/src/materials.test.ts` **18/18** (EXIT 0) · `npm run worker:typecheck` bersih (EXIT 0) · `npm test` **142/142** (18 berkas) + fixture 4/4 + katalog 336/336 + binding PASS · `npm run catalog:dev` ulang → sha256 ZIP ketiga bundel demo identik dengan sebelum refactor (`0a6765c1e54f…`, `6c14a97430d8…`, `f7c52c954e5d…`) · pemeriksaan alur `.tmp-publish/check.ts` (gitignored; Supabase ditiru di proses yang sama, `wrangler` tidak dipakai): `material-publish.mjs` menerbitkan `fakta-opini-kelas4` → **EXIT 0**, 2 objek terunggah, 1 baris tersimpan, **tanda tangan Ed25519 terverifikasi atas manifest tersimpan**, `GET /v1/materials` → 200 dengan 1 item berkeys `materialId,version,publishedAt,updatedAt,sizeBytes,bundleSha256,downloadUrl,signature,material,coverUrl` + URL pre-signed.

Diperbaiki dengan `ZIP_ENTRIES` + `zip` di cakupan modul; dua cacat tipe ikut diperbaiki (`reduce` atas `never[]`, `sizeBytes` tidak ada di anotasi body). **Bug test, bukan bug produk** — test lain tidak dilonggarkan.
