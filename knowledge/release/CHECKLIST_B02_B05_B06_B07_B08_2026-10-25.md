## B-02 — Backup & Rotasi Kunci Lisensi

### Fakta saat ini

| Item | Nilai |
|---|---|
| Private key | Secret Worker `LICENSE_SIGNING_PRIVATE_KEY` (tidak di repo) |
| Public key | `LICENSE_PUBLIC_KEY` di `workers/api/wrangler.toml` |
| Key ID | `prod-1` |
| App | Public key di-embed saat build via `IFP_LICENSE_KEYS` |

### A. Inventaris

- [ ] Catat fingerprint public key `prod-1`: ______________________
- [ ] Catat pemegang akses secret Cloudflare: ______________________
- [ ] Catat lokasi backup terenkripsi (2 lokasi): ______________________

### B. Backup

1. [ ] Ambil private key dari sumber aman (secret manager/Cloudflare), **jangan** lewat chat/repo.
2. [ ] Enkripsi dengan age/GPG:
   ```bash
   age -r <penerima> -o prod-1.key.age prod-1.key
   ```
3. [ ] Simpan di dua lokasi aman; catat SHA-256 file terenkripsi.
4. [ ] Uji restore di lingkungan terisolasi: derive public key dan bandingkan dengan `LICENSE_PUBLIC_KEY`.
   ```bash
   openssl pkey -in prod-1.key -pubout -outform DER | base64 -w0
   ```
5. [ ] Hapus salinan plaintext setelah backup terverifikasi.

### C. Rotasi (bila perlu)

1. [ ] Generate `prod-2`:
   ```bash
   openssl genpkey -algorithm ED25519 -out prod-2.key
   ```
2. [ ] Public key baru:
   ```bash
   openssl pkey -in prod-2.key -pubout -outform DER | base64 -w0
   ```
3. [ ] Private PKCS8 base64 untuk secret Worker:
   ```bash
   openssl pkcs8 -topk8 -nocrypt -in prod-2.key -outform DER | base64 -w0
   ```
4. [ ] Set secret `LICENSE_SIGNING_PRIVATE_KEY` ke nilai `prod-2`.
5. [ ] Set `LICENSE_KEY_ID=prod-2`; deploy Worker.
6. [ ] Build aplikasi dengan `IFP_LICENSE_KEYS` memuat `prod-1` **dan** `prod-2` selama masa transisi.
7. [ ] Uji aktivasi/refresh baru → signature `prod-2` terverifikasi.
8. [ ] Setelah semua klien terbarui, hapus `prod-1` dari daftar.

### D. Definisi selesai

- [ ] Backup terenkripsi terverifikasi (restore test)
- [ ] Fingerprint `prod-1`/`prod-2` tercatat
- [ ] Rotasi diuji di lingkungan uji
- [ ] Prosedur darurat (kompromi kunci) tertulis
